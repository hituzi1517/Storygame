# Ipomoea — 夜明けの証言

GitHub Pagesにそのまま置ける、全6章のミステリー・アドベンチャーです。
背景画像・プログラムはすべて同梱。ビルドや追加パッケージは必要ありません。
GitHub版にはChatGPTのログイン機能はありません。

## アップロード方法

1. ZIPを展開します。ZIPそのものではなく、中のファイルと `assets` フォルダーをアップロードします。
2. GitHubでリポジトリを作り、`index.html` がリポジトリの一番上に来るように中身を置きます。
3. リポジトリの Settings → Pages を開きます。
4. Sourceで Deploy from a branch を選び、Branchを main、フォルダーを / (root) にして Saveします。
5. 公開処理が完了したら、Pages画面に表示されるURLを開きます。

画像が表示されない場合は、assetsフォルダーもアップロードしたか確認してください。
ファイル名の大文字・小文字やフォルダーの位置は変更しないでください。

## ファイル

- index.html：入口
- style.css：画面のデザイン
- app.js：操作・表示・セーブ・環境音
- model.js：ゲームの進行
- data.js：物語・会話・証拠・パズル
- icon.svg：アイコン
- assets/：背景画像5枚
- .nojekyll：静的ファイルをそのまま配信する指定

## セーブを移す場合

進行はブラウザ内に保存されます。以前のサイトとGitHub Pagesでは保存場所が別です。
以前のゲームで「設定 → セーブを書き出す」を選び、新しいゲームで「設定 → セーブを読み込む」と続きから遊べます。
端末・ブラウザを変える時も同じ手順です。

## 内容と原作

ニル／アルバの視点による調査・選択会話、32件の証拠、6件の任意の発見、7つのパズル。
人物の立ち絵・スチルはなく、人物を含まない生成背景5枚を使用しています。
『Ipomoea 改稿版・長編小説制作バイブル』の事件をゲーム向けに再構成しています。
会話、章構成、書類番号、パズルの具体的な手順・強度はゲーム用の補作です。
原作の設定を追加確定するものではありません。
